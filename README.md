# Goddard Soccer League Website
Welcome to the new official website of the Goddard Soccer League

[goddard-soccer.github.io](https://goddard-soccer.github.io)

## Developers
- Host: `Github pages`
- Pre-processor: `zola`
    - this is a super useful tool that generates the site for us from all the templates so we don't have to write as much code or copy paste
- Style-processor: `sass`
    - this is essentially the same idea as zola, a preprocessor, but it just generates the css (styles) for us
- Data Processing: `tera`
    - this is a language built into zola that can do things with our data files or further assist in generating individual files
- Libraries: `bootstrap`
    - this is a super useful framework that further helps with skeleton (html) items and does a lot of the heavy lifting for the styles within the html (.mb-3 translates to margin-bottom: 15px for instance)

### Local hosting commands
```bash
zola serve -i 0.0.0.0
```

### Structure
- content -> the actual pages for the site
- data -> "database" to capture schedule/titles
- publish -> (hidden unless building locally) files for actual site, auto-generated by zola
- static -> stuff that doesn't change - images, docs, fonts, etc
- templates -> "templates" for a web page/post, wraps the stuff common to each page (ie navbar include)
- templates/components -> small pieces of code that are reused in several places
- zola.toml -> zola settings, have to restart zola if you make changes

### Notes
- Markdown -> HTML
- Sass -> CSS
- Tera -> Code Loops/Statements on HTML
- Bootstrap Library -> JS/CSS
